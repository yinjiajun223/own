## 题目描述

罗马数字包含以下七种字符： `I`， `V`， `X`， `L`，`C`，`D` 和 `M`。

```
字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

给你一个整数，将其转为罗马数字。

## 示例

```
输入: num = 3
输出: "III"
```

```
输入: num = 4
输出: "IV"
```

```
输入: num = 9
输出: "IX"
```

```
输入: num = 58
输出: "LVIII"
解释: L = 50, V = 5, III = 3.
```

```
输入: num = 1994
输出: "MCMXCIV"
解释: M = 1000, CM = 900, XC = 90, IV = 4.
```
