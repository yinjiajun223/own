## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

## 示例

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

```
输入：s = ""
输出：0
```
