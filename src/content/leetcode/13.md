## 题目描述

罗马数字包含以下七种字符: `I`， `V`， `X`， `L`，`C`，`D` 和 `M`。

```
字符          数值
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

给定一个罗马数字，将其转换成整数。

## 示例

```
输入: s = "III"
输出: 3
```

```
输入: s = "IV"
输出: 4
```

```
输入: s = "IX"
输出: 9
```

```
输入: s = "LVIII"
输出: 58
解释: L = 50, V= 5, III = 3.
```

```
输入: s = "MCMXCIV"
输出: 1994
解释: M = 1000, CM = 900, XC = 90, IV = 4.
```
