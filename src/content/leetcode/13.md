## 题目描述

罗马数字由七个不同的符号表示：`I`、`V`、`X`、`L`、`C`、`D` 和 `M`。

| 符号 | 值   |
| ---- | ---- |
| I    | 1    |
| V    | 5    |
| X    | 10   |
| L    | 50   |
| C    | 100  |
| D    | 500  |
| M    | 1000 |

例如，`2` 写作 `II`，即两个 1 相加。`12` 写作 `XII`，即 `X + II`。`27` 写作 `XXVII`，即 `XX + V + II`。

通常情况下，罗马数字中小的数字在大的数字的右边。但也存在特例，例如 4 不写做 `IIII`，而是 `IV`。数字 1 在数字 5 的左边，所表示的数等于大数 5 减小数 1 得到的数值 4。同样地，数字 9 表示为 `IX`。这个特殊的规则只适用于以下六种情况：

- `I` 可以放在 `V`（5）和 `X`（10）的左边，来表示 4 和 9。
- `X` 可以放在 `L`（50）和 `C`（100）的左边，来表示 40 和 90。
- `C` 可以放在 `D`（500）和 `M`（1000）的左边，来表示 400 和 900。

给定一个罗马数字，将其转换成整数。

## 示例

**示例 1：**

```
输入: s = "III"
输出: 3
解释: III = 3
```

**示例 2：**

```
输入: s = "LVIII"
输出: 58
解释: L = 50, V= 5, III = 3
```

**示例 3：**

```
输入: s = "MCMXCIV"
输出: 1994
解释: M = 1000, CM = 900, XC = 90, IV = 4
```

## 约束条件

- `1 <= s.length <= 15`
- `s` 仅包含字符 `('I', 'V', 'X', 'L', 'C', 'D', 'M')`
- 题目数据保证 `s` 是一个有效的罗马数字，且表示整数在范围 `[1, 3999]` 内

## 我的解题过程

### 解法：双字符比较法

将字母的映射关系存到一个对象里，然后遍历字符串，比较当前字符和下一个字符的大小关系：

- 如果当前字符的值大于等于下一个字符的值，则加上当前字符的值
- 如果当前字符的值小于下一个字符的值，则减去当前字符的值，并加上下一个字符的值，同时跳过下一个字符

```ts
function romanToInt(s: string): number {
  let res = 0;
  const numsMap = {
    I: 1,
    V: 5,
    X: 10,
    L: 50,
    C: 100,
    D: 500,
    M: 1000,
  };

  for (let i = 0; i < s.length; i++) {
    const curChar = s[i];
    const nextChar = s[i + 1] || 0;

    if (numsMap[curChar] >= (numsMap[nextChar] || 0)) {
      res += numsMap[curChar];
    } else {
      res += numsMap[nextChar] - numsMap[curChar];
      i++;
    }
  }
  return res;
}
```

## 解题思路

**核心逻辑：**

罗马数字的规则是从左到右，大数字在前面。但是遇到减法规则时（如 IV、IX、XL 等），小数字会在大数字前面。因此：

- 当前数字 ≥ 下一个数字：直接加上当前数字
- 当前数字 < 下一个数字：这是一个减法组合，用 `下一个数字 - 当前数字` 得到结果，并跳过下一个字符

**算法步骤：**

1. 创建罗马数字到整数的映射表
2. 遍历字符串，每次查看当前字符和下一个字符
3. 如果当前字符值 ≥ 下一个字符值，累加当前值
4. 如果当前字符值 < 下一个字符值，累加 `下一个值 - 当前值`，并跳过下一个字符
5. 返回累加结果
