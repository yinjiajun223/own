## 题目描述

将一个给定字符串 `s` 根据给定的行数 `numRows`，以从上往下、从左到右进行 Z 字形排列。

比如输入字符串为 `"PAYPALISHIRING"` 行数为 `3` 时，排列如下：

```
P   A   H   N
A P L S I I G
Y   I   R
```

之后，你的输出需要从左往右逐行读取，产生出一个新的字符串，比如：`"PAHNAPLSIIGYIR"`。

## 示例

```
输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"
```

```
输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
解释：
P     I    N
A   L S  I G
Y A   H R
P     I
```

```
输入：s = "A", numRows = 1
输出："A"
```

## 我的解题过程

### 思路分析

最初没有找到好的解法，参考题解后发现了规律：

**核心思路：** 模拟 Z 字形填充过程，使用数组按行存储字符。

1. 创建长度为 `numRows` 的数组，每个元素代表一行
2. 遍历字符串，按 Z 字形顺序将字符填入对应行
3. 使用方向标记控制上下移动：
   - 到达顶部（第 0 行）时向下移动
   - 到达底部（第 `numRows - 1` 行）时向上移动
4. 最后将所有行拼接成结果字符串

### 代码实现

```typescript
function convert(s: string, numRows: number): string {
  if (s.length <= 2 || numRows === 1) return s;

  const rows: string[] = new Array(numRows).fill("");
  let currentRow = 0;
  let down = true;

  // 遍历字符串，按 Z 字形填充
  for (let i = 0; i < s.length; i++) {
    rows[currentRow] += s[i];

    // 到达边界时改变方向
    if (currentRow === 0) {
      down = true;
    } else if (currentRow === numRows - 1) {
      down = false;
    }

    // 根据方向移动到下一行
    currentRow += down ? 1 : -1;
  }

  // 拼接所有行得到最终结果
  return rows.join("");
}
```
